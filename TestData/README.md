# Synthetic test data

These `.tli` files contain synthetic, work-related examples for trying out TimeLiner without exposing real production data.

- `web-request.tli` shows a request flowing through a gateway, service, cache, and database.
- `deployment.tli` shows a build and deployment pipeline with staging and production steps.
- `background-job.tli` shows parallel workers and a warning during a nightly import.

All timestamps, names, and values are fictional. Colors are used to distinguish phases, parallel work, warnings, and successful completion.
